# Security

This project is an early preview. Supported security fixes target the latest release.

Report vulnerabilities through GitHub's private vulnerability reporting, if enabled, on the repository's Security tab. Otherwise open an issue requesting a private contact without including exploit details, source code secrets, or credentials. Do not publish live tokens in issues.

Security boundaries include the configured MCP workspace, exact source anchors, explicit selection before AI requests, protected local token storage, and the absence of automatic source writes or command execution. A generated plan is untrusted guidance; inspect it before typing and test the resulting code.
