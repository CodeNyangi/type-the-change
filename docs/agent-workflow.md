# Type the Change local preview

Use **`>_` in the Activity Bar** or **⌘⌥⇧T / Ctrl+Alt+Shift+T**. The Activity Map places Codex and Claude Code next to each other beside the editor.

- **Threads** shows the open project's Codex app history, recent local Codex and Claude Code records, and explicitly linked Claude cloud sessions. Expand a thread to load its recorded changes. **Show more** reveals older entries already found for this project. Choose a file to open its recorded diff beside the available reason. A nearby general message is labeled **Before the edit**. **Current file** opens today's source or Git diff.
- **Send to an Agent** uses an installed, signed-in CLI. For new or saved local sessions, choose the provider, model and effort. The defaults are GPT-6.2 Sol and Claude Opus 5.5 at Medium. For inexpensive checks, choose GPT-6 Luna or the pinned Claude Haiku 4.5 at Low. Opus 5.5 requires Claude Code 2.1.280 or newer and an account that can use it. On older Claude Code versions and Haiku 4.5, the extension uses a fixed thinking budget. A request started from a local file includes bounded excerpts of its saved code and Git diff.
- **Link cloud session** accepts a Claude Code work link from Desktop or the web. The same thread appears under Claude Code. **Send to this thread** queues the message there using Claude Code's existing cloud model and permissions. A linked report can supply its recorded code and reason.
- **Request a Change to Type** is available from a file's context menu. A matching response becomes a local proposal. Predict, edit, check the diff or tests, then record your decision. The existing Codex learning reader remains available in the right sidebar.

Direct local sends use Codex's read-only sandbox and Claude's plan mode. Active or app-only Codex chats receive messages in the original owner via the Codex CLI queue, with that chat's existing model and permissions. A running Claude local session is kept in view while its owner is using it. Cloud links expose connected sessions, with the existing thread receiving the request and local Git evidence appearing when a report supplies a commit. Account-wide Claude cloud history and real-time cloud changes are unavailable in this view. The current local files and Git changes remain accessible separately.

For an agent already running elsewhere, use the sidebar menu **Show MCP Connection**. Add each generated entry to its matching client for this workspace. An agent can call `propose_typing_plan` with an assessment or `report_change_review` with its impact, risk, verification, and file locations. If it includes the matching local thread ID, that review appears with the thread. A Claude web explanation can also cite an explicit source URL and local commit in the report. Its file opens the Git evidence and the explanation beside it. Each agent retains its own latest proposal and review. Keep `.type-the-change/` ignored by Git.
