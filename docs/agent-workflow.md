# Type the Change local preview

Use **`>_` in the Activity Bar** or **⌘⌥⇧T / Ctrl+Alt+Shift+T**. The Activity Map places Codex and Claude Code next to each other beside the editor.

- **Threads** reads recent local session records for trusted, open folders. Select a file to see the recorded diff and the available explanation together. A nearby general message is labeled **Before the edit**. Use **Current file** to see today's source or Git diff. **Ask why** can request a file-specific explanation from the same thread. The view refreshes while visible, after the agent writes its log.
- **Send to an Agent** uses an installed, signed-in Codex or Claude Code CLI. Pick a provider, a new or recent local thread, and a model. The defaults are GPT-6.2 Sol and Claude Opus 5.5, both at Medium. For inexpensive checks, select GPT-6 Luna or the pinned Claude Haiku 4.5 model and Low. High is also available. Enter a supported model ID to select another model. On older Claude Code versions and on Haiku 4.5, TTC uses fixed thinking budgets of 0, 2,048 or 4,096 tokens instead of passing the newer effort flag. Enter the request in VS Code. Claude replies include the model IDs reported in CLI usage when available. Opus 5.5 requires Claude Code 2.1.280 or newer and an account that can use it. When started from a file, the request sends bounded excerpts of its saved code and Git diff.
- **Request a Change to Type** is available from a file's context menu. A matching response becomes a local proposal. Predict, edit, check the diff or tests, then record your decision. The existing Codex learning reader remains available in the right sidebar.

The direct send route uses Codex's read-only sandbox and Claude's plan mode. It keeps CLI sessions so supported local clients can reopen them. It does not send messages to regular ChatGPT chats, cloud-only Claude sessions, or a chat UI via desktop automation. Available models and successful resumption depend on the installed CLI and account. A CLI writing to a different profile does not appear in the default local activity feed. The feed reads only recent recognizable edit events, so shell-based edits and worktrees open elsewhere may appear only in Git or in their own workspace.

For an agent already running elsewhere, use the sidebar menu **Show MCP Connection**. Add each generated entry to its matching client for this workspace. An agent can call `propose_typing_plan` with an assessment or `report_change_review` with its impact, risk, verification, and file locations. If it includes the matching local thread ID, that review appears with the thread. A Claude web explanation can also cite an explicit source URL and local commit in the report. Its file opens the Git evidence and the explanation beside it. Each agent retains its own latest proposal and review. Keep `.type-the-change/` ignored by Git.
