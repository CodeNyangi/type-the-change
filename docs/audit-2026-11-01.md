# Type the Change 검증 — 2026-11-01

## 대상과 결론

- 기준 저장소: `CodeNyangi/type-the-change`, `92b1c5490b11d1affd0fac467bb20d1d5e5feb92` / 0.2.0.
- 구현 목표: Codex Desktop 없이 VS Code에서 요청 → 선택 파일로 수정안 생성 → 네이티브 편집기에서 직접 입력 → 비교/다음 단계. MCP는 선택 사항이며 자동 수정·자동 저장·학습 퀴즈는 추가하지 않는다.
- 공개 기준 커밋의 별도 로컬 작업 사본에서 검증했다. 다른 작업 사본의 미커밋 변경이나 설치 상태는 검증 범위에 포함하지 않았다.
- 재현되거나 규격으로 확인된 문제를 로컬 작업 사본에서 수정했다. 수정은 검토용 브랜치와 PR로 제출하며, 병합·릴리스는 소유자의 검토 뒤 별도로 진행한다. 별도 데이터 디렉터리와 새 `Type the Change QA` 프로필에 검토용 확장을 설치했으며 기본 프로필에는 추가하지 않았다.

**현재 판정:** 전체 자동 검사 120개, 실제 VS Code 확장 호스트와 필수 네이티브 타이핑 검증, 동일 웹뷰의 브라우저 클릭·시각 검수가 통과했다. 별도 프로필에 설치된 시작 화면도 직접 확인했다. 이후 화면 조작 도구가 `noWindowsAvailable`, 오래된 화면, 접근성 상태와 캡처 불일치, 시간 초과를 반환하여 전체 수동 동선의 검증은 완료하지 못했다. 이후 사용자 요청으로 GUI 조작을 중단했다. 실제 ChatGPT 계정 동의/구독 추론도 미완료다. 모든 실사용 흐름의 최종 승인으로 해석하면 안 된다.

## 남은 실사용 검증과 현재 제품 제한

1. 화면 조작 연결이 실제 창을 안정적으로 읽을 수 있는 상태에서 한국어 IME, 새 파일 체크 목록/모델 선택, 포커스 복귀와 전체 동선을 수동 확인. Mac 잠금 해제 후 필수 네이티브 타이핑은 최신 코드에서도 통과했으므로, 남은 제한을 ‘Mac이 잠겨 있음’으로 단정하지 않는다.
2. 실제 ChatGPT 계정으로 최초 동의 → 모델 목록 → 선택한 샘플 파일의 추론 → 타이핑 → diff → 연결 해제. 사용자 계정 자격증명을 읽거나 재사용하지 않았다.
3. 갱신한 작업 사본의 Linux 필수 타이핑 CI는 아직 실행하지 않았다. 기존 공개 커밋의 성공과 구분한다.
4. 패키징 개발 의존성 advisory [GHSA-g3hv-75wg-m249](https://github.com/advisories/GHSA-g3hv-75wg-m249)는 업데이트 경로가 제공되면 재검토한다. 강제 메이저 override는 하지 않았다.

기존 파일만 수정하며 새 파일·rename·remote workspace는 지원하지 않는다. 정확한 공백/문자 일치를 요구하고 사용자가 다른 구현을 선택해 승인하는 흐름은 없다. 편집을 그대로 따라 입력했다는 사실은 의미 이해·정확성·테스트 성공을 증명하지 않는다. 이는 현재 제품 범위이며 이번 점검에서 교육 효과가 검증된 것은 아니다.
