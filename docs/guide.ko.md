# 사용법

## 기존 채팅 따라가기

⌘⌥T / Ctrl+Alt+T로 Type the Change를 열고 원래 제목의 Codex 채팅을 선택하세요. 이름으로 찾거나 이전 채팅을 더 불러올 수 있습니다. 채팅 ID로 작업을 구분하며 새 에이전트나 복제 대화를 만들지 않습니다. 추가 요청은 **Codex에서 이어가기**로 같은 채팅에서 진행합니다.

**대화**에는 공개 메시지, 계획, 명령 진행, 파일 수정 기록이 표시됩니다. 과거 기록은 페이지로 나누어 읽습니다. 명령 실행 내역은 필요할 때 펼쳐 볼 수 있습니다. 원본은 Codex에 있고 TTC는 화면에 필요한 제한된 기록만 잠시 메모리에 보관합니다.

## 실제 진행 상태 연결

먼저 Codex의 기존 공유 연결을 확인합니다. 연결되면 해당 서버의 실행·대기·승인 상태를 읽습니다. 기록 조회만 가능한 경우 다른 Codex 프로세스의 실행 여부를 알 수 없으므로, **저장된 기록**으로 표시합니다. 마지막 확인 시각은 **작업 정보**에서 볼 수 있습니다.

macOS/Linux에서는 **실시간 알림 연결**로 Codex의 공식 알림 설정을 추가할 수 있습니다. 설정 차이를 먼저 표시하고 기존 알림 설정을 보존합니다. 추가한 뒤 **터미널에서 Codex CLI를 실행하고 `/hooks`를 입력**하세요. 이벤트를 고르고 Enter를 누르면 `Type the Change: observe Codex`의 활성·허용 상태를 볼 수 있습니다. 이미 체크되어 있고 `Trusted`이면 추가 허용은 필요 없습니다. 미허용 상태라면 내용을 확인하고 허용한 후 원래 채팅에서 계속하세요. Codex는 허용하지 않은 알림 설정을 실행하지 않습니다. 이미 실행 중인 작업에 소급해서 붙지는 않으며, Codex가 새 설정을 불러와야 합니다. 실제 알림이 도착하면 TTC에서 연결을 확인할 수 있습니다.

요청 접수, 도구 실행·완료, 승인 대기, 대화 정리, 응답 마무리, 중단·세션 종료처럼 실제로 받은 알림을 표시합니다. **응답 마무리**는 최종 완료 판정이 아닙니다. Codex의 다른 설정에 따라 작업이 이어질 수 있습니다. 오래된 알림은 현재 실행 중이라고 표시하지 않습니다. 알림 기능은 문맥·기억을 추가하거나 작업을 승인·재시작하지 않으며 모델 요청도 하지 않습니다.

사용 중인 Codex가 별도의 공유 Unix 소켓을 제공한다면 `typeTheChange.codexSocket`에 설정할 수 있습니다. TTC가 원래 Codex 서버를 재설정하거나 재시작하지 않습니다. Windows에서는 기록 조회를 사용할 수 있지만 이 로컬 알림 기능은 지원하지 않습니다.

## 변경점에서 배우기

**VS Code 소스 제어**에서 변경을 여세요. TTC의 **지금 보는 코드**가 열린 파일과 커서가 있는 변경 구간을 따라갑니다. TTC 안에서 파일을 다시 고르지 않습니다. 채팅과 다른 워크트리의 파일이면 그 차이를 표시합니다. 연결된 브랜치·경로는 **작업 정보**에서 확인하거나 선택할 수 있습니다.

스테이징된 변경과 미스테이징 변경은 편집기에 열린 비교의 양쪽 내용을 그대로 사용합니다. 일반 파일 편집기에서는 마지막 커밋과 현재 내용을 비교하며, 저장 전 수정도 포함합니다. 읽는 파일은 선택한 채팅의 등록된 워크트리 안에 있어야 합니다.

Codex가 남긴 관련 설명이나 해당 수정의 원래 요청을 짧게 보여줍니다. **원래 대화 펼치기**로 전체 맥락을 확인하세요. TTC가 새 설명을 생성하지 않습니다. **편집기에서 변경 보기**는 고정된 시점의 읽기 전용 비교를 엽니다. 소스 제어 비교를 이미 보고 있으면 이 단계를 다시 거치지 않습니다.

짧은 수정에는 **이 부분 직접 바꾸기**가 나타납니다. 별도 문서에서 바꿔 보고 **내 코드 비교**로 Codex의 코드와 비교하세요. 힌트는 필요할 때 펼칩니다. 새 파일·삭제·큰 구간 전체를 따라 쓰게 하지 않으며, 연습 내용이 원본에 덮어써지지 않습니다. 텍스트가 같다는 결과는 동작이나 이해도를 보장하지 않습니다.

커밋된 수정은 **지난 Codex 수정**을 펼쳐 찾습니다. 실행 로그를 건너뛰어 수정 기록을 찾으며, 더 오래된 기록은 **이전 수정 더 보기**로 이어서 읽습니다. 기록은 당시의 코드이므로 현재 파일과 다를 수 있습니다.

작업 중 코드가 바뀌면 보고 있던 비교를 유지하고 새 변경을 알립니다. **최신 변경**으로 다시 확인하세요. **파일 정보 → 현재 파일 열기**는 기록 속 구간을 현재 소스에서 찾아 엽니다. 해당 구간이 사라졌거나 여러 곳에 있으면 파일 처음을 엽니다. TTC가 원본을 되돌리거나 커밋·워크트리를 만들지 않습니다.

## 위치·언어·선택 기능

**설정 · 사용법 → 위치**에서 VS Code의 기본 위치 선택 메뉴를 엽니다. 기본은 오른쪽이며 이후 선택은 VS Code가 기억합니다. **설정 · 사용법 → 언어**에서 자동·한국어·영어를 고릅니다. 코드와 Codex 메시지는 원래 언어로 표시합니다.

명령 팔레트의 **수정안 가져오기**, **MCP 수정안 열기**, **수정·검사 연습**은 이전 방식의 선택 기능입니다. 이 방식은 직접 원본을 편집하고 검사를 명시적으로 선택합니다. 파일당 64 KiB의 UTF-8 코드를 지원하고 로컬 학습 기록을 남기지만 TTC 에이전트를 호출하지 않습니다. [개인정보](../PRIVACY.md)를 참고하세요.
