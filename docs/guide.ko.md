# Codex 변경 이해하기

작업을 고르세요. 현재 프로젝트와 연결된 워크트리의 최근 작업 5개부터 표시합니다. 더 오래된 작업이나 다른 프로젝트는 목록에서 직접 펼칠 수 있습니다.

설명이 없다면 **Codex에 변경 설명 요청**을 누르세요. TTC가 요청문을 복사하고 원래 Codex 채팅을 엽니다. 사용자가 붙여넣어 전송해야 합니다. TTC가 메시지를 대신 보내거나 다른 에이전트를 실행하지 않습니다. 기존 작업이 진행 중이면 방해하지 말고 작업이 끝난 뒤 요청하세요.

Codex는 이미 수행한 코드 변경에서 개념 하나, 12줄 이하의 코드, 무엇이 달라졌고 왜 필요한지에 대한 짧은 설명을 작성합니다. TTC는 `ttc-lesson` 형식의 명시적인 카드만 읽습니다. 일반 답변·설치 안내·로그·파일 정보로 학습 자료를 추측하지 않습니다.

변경 이유와 바뀐 코드를 처음부터 보여줍니다. 질문·선택지·정답 단계는 없습니다. 바꾸기 전 코드는 필요할 때 펼칩니다. 긴 코드 줄도 사이드바 너비 안에서 줄바꿈합니다.

**실제 수정 확인**은 카드의 코드와 연결된 읽기 전용 비교입니다. 원본을 편집하거나 되돌리지 않습니다. 카드의 전후 코드는 같은 채팅의 실제 수정 기록과 대조합니다. 이미 삭제된 워크트리는 기록 속 절대 경로와 패치를 확인한 경우에만 과거 코드로 비교하며, 그 경로의 현재 파일을 읽거나 열지 않습니다. 기록을 확인하지 못하면 카드를 표시하지 않고 다시 확인할 수 있습니다.

설명은 화면에 필요한 제한된 정보만 메모리에 유지하며 별도 대화·학습 메모리로 저장하지 않습니다. 원본 카드는 Codex 채팅에 남습니다. 작업의 새 요청과 실행도 원래 Codex에서 계속합니다.

**설정**에서 언어·위치·Codex 실행 파일을 고릅니다. 실시간 알림은 선택 기능이며 기존 알림 설정 검토와 Codex CLI의 `/hooks` 허용 절차를 따릅니다. 카드 기록 조회에는 알림 설정이 필요하지 않습니다.

이전 수정안 가져오기·MCP·직접 수정·검사는 명령 팔레트의 선택 기능입니다. [이전 영상](../assets/type-the-change-quickstart.mp4)과 [개인정보](../PRIVACY.md)를 참고하세요.
