# Type the Change media

`icon.svg` is the source of the minimal project mark: an open code prompt and an
input cursor. It represents staying involved in the code by making your own input
and decisions. The final mark contains no text, dot, or animal illustration.
`scripts/render-icon.mjs` exports the 256px extension icon and 128px publisher
icon from the same vector using a headless browser.

The walkthrough and GIF record the actual extension in an isolated Linux VS Code
session using the built-in **Try demo**. English controls, notes and burned-in
captions show the editor icon, prediction, failed check, rejection and correction.
`releases` include the separate English subtitle track. All project-authored assets
follow the repository's MIT license.
